# Track 2 validation: accessibility, real-browser evidence (agent A11Y)

Date: 2026-10-30. Evidence only, WCAG 2.2 AA oriented. "No failure observed" means exactly that for the states and sizes listed. It is not a conformance statement. **Automated and scripted checks do not replace an assistive-technology pass** (screen reader, switch, voice control, real devices); none was done here.

## Setup (reproduced here)
- Chrome 156.0.8078.79 headless (`--headless=new`) driven over CDP, throwaway profiles under `D:/Temp`, Windows 11. Relaunched every 3 cold loads; route changes inside a session use the hash router.
- UI: Vite dev server, port 3200 (`--strictPort`), unminified dev build, UI frozen. Gateway: debug build `D:\Personal\_m7_target\debug\phantom-cache-demo.exe`, `127.0.0.1:8285`, anonymous loopback, Lab enabled, `PHANTOM_LAB_DIR=D:\Temp\a11y_lab` holding only the copied M6 and Scenario B evidence files. UI used `?gateway=http://localhost:8285` and `VITE_PHANTOM_GATEWAY`; `localhost` throughout.
- Runs created through the UI: Scenario B quick check (1 rep, BASE + STATIC-CAP, 1 s phases) `20261030T090346Z-a6d4d776` (completed), T1 smallest/smoke `20261030T090401Z-e2b2732c` (completed), plus two Scenario B runs cancelled for the dialog test.
- Script: `ui/scripts/browser-a11y-final.mjs` (phases prep, matrix, ax, kbd, media, scale, prov, disconnect). Evidence: `docs/design/remediation/a11y_evidence/` (`*.results.json(.jsonl)`, `matrix_<w>.detail.json`, `ax_summary.1280.json`, `kbd_traversal.json`, `kbd_interact.results.jsonl`, `media_*.json`, `scale_results.json`, `prov_detail.json`, `shots/`, `logs/`).
- Routes (16): overview, traffic, cache, freshness, origin, cluster, intelligence, simulation, lab home, lab evidence list, M6 evidence, Scenario B evidence, start-a-run form, runs list, run detail (Scenario B), run detail (T1). Themes light and dark (emulated `prefers-color-scheme`). Viewports 320, 390, 640, 820, 1280.
- Harness corrections made during the run (not UI defects): (a) CDP `Enter` needs `text:'\r'` for keypress-activated controls (summary, submit); my first kbd pass reported Enter failures that disappeared once fixed; the superseded attempt is `logs/kbd_attempt1.jsonl`. (b) The first contrast pass treated `linear-gradient(transparent, transparent)` (used by the UI for press tints) as a background image, giving many "indeterminate" nodes; fixed, final indeterminate count is 0. (c) The text-scale pass first reused a polluted document; rerun with reset. (d) One forced-colors run hung after a `prefers-contrast` run in the same Chrome; modes were then run in separate processes.
