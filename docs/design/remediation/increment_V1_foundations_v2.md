## 1. What changed, by DD step
1. **Tokens** (`tokens.css`). Neutral ladder replaced (DD 4.2 values; `--surface-3`, `--primary`/`--on-primary` added). Material tokens (`--glass-1/2`, `--glass-edge`, `--glass-hair`, `--blur-1/2`, `--sat`), `--grid-line`, `--hatch`, eyebrow type tokens, `--radius-control/-card`, `--space-region`, `--header-h`, motion tokens `--d-press/-fast/-base`, `--ease-in-out`, `--ease-spring` (plain ease-out fallback, `linear()` under `@supports`, no overshoot). Every old token name still exists, except `--radius-pill` (see deviations). Display type 2 rem (1.5 rem on phones), weights 650, tracking -0.03em.
2. **Materials** (`app.css` "Materials"). Glass on four chrome surfaces only: header (all widths), rail (>= 820 px), run bar (`.form-bar`, >= 820 px), dialog (>= 820 px). Ladder: solid default, glass inside `@supports (backdrop-filter)`, solid again for `prefers-reduced-transparency`, `prefers-contrast: more`, `forced-colors`. Phones: header is the only glass surface; menu sheet, run bar, dialog are solid. Alphas 0.90 light / 0.88 dark (both glass tokens). Edge = hairline plus lighter top border (no inset shadow, keeps the old shadow-token rule).
3. **Shell** (`Shell.jsx`, `shell.css`). Sticky 56 px header (static on viewports shorter than 30 rem), ghost mark (`GhostMark`, new export in `Icon.jsx`), status unchanged in data (`StatusPill`, new `data-conn-kind` attribute), theme as a native `<details>` menu with a solid popover (Escape and outside press close it, focus returns), `--header-h` published from the measured header height (ResizeObserver) so the rail, the phone sheet and `scroll-padding-top` follow text scaling. Rail 14.5 rem, sticky below the header, "Not available yet" folded into a `<details>` showing its count (open by default, state remembered in `localStorage` inside try/catch, key `phantom.ui.nav.unavailable-open`; arrow keys still reach every link and open the fold). Phone menu is a fixed solid sheet under the header (reachable at any scroll). Gateway block kept at the rail foot.
4. **Components** (`app.css`). Primary button ink-filled; secondary outlined; `.pill` is now a 5 px-radius indicator (no 999 px anywhere); provenance mark 22 px high, qualifier wraps instead of widening the page; `.stamp` (RETAINED stamp style, solid ink) added for V2 to use; notices have a heavy left rule and ink text; tabs get a 2 px ink underline that slides by `scaleX`; hatched ground (`.hatch`, and unavailable/empty state blocks); inputs use `--surface-2` wells; metric numerals 30 px.
5. **Motion** (`app.css`, `shell.css`). New `pc-pop` (opacity + scale 0.97) for popovers and dialogs; phone dialog and phone menu sheet fade only; all reduced-motion equivalents in the single `prefers-reduced-motion` block; `.btn` colour transition under reduce is 90 ms linear and has no transform transition.

## 6. Deviations from DD v2 (deliberate)
- Popovers and menus are solid, not glass-2: the only popover opens from the glass header (DD 4.3 forbids glass on glass).
- `glass-2` uses the same alpha as `glass-1` (0.90 / 0.88): at DD's 0.86 / 0.84 the run bar's error and state text did not hold the 4.5:1 worst case.
- Eyebrow is 12 px, not 11 px (project floor, existing test). Slow motion tier (280 ms) not defined (unused tokens are a test failure; nothing needs it).
- Rail glass: nothing scrolls under the rail (content is beside it), so its blur is visually moot; kept because DD 7.1 names it. Dropping `glass-1` on `.app-nav__panel` is a one-line change if the owner prefers 3 desktop glass surfaces.
- `--radius-pill` removed (unused after `.pill` was restyled; the old unused-token test requires use).
- Dialog exit and popover exit are not animated (native `<dialog>` closes instantly; DD 6.2 exit needs script). Popover/dialog `transform-origin` is the trigger only for the theme menu.
- Header connection popover, gateway "Change address", test-connection: not built (logic belongs to the connection agent).
