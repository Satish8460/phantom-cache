Start here

PhantomCache is a caching gateway: it sits in front of a slow server (the origin) and remembers answers, so the same question is answered fast the next time and the slow server is bothered less. This page lets you watch it work, live, with real pictures and real requests. Nothing here is simulated.

1. Start the cluster.
Three gateways (nodes) and one origin run on this machine. One button starts them.
2. Press "Demonstrate" on any card.
The real test runs and every step appears in the live feed, with what it means in plain words.
3. Read the verdict.
Each card ends with Passed, Shows ..., or Needs attention, plus the real numbers.
